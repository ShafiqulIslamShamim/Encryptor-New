## 🚀 Features

### 🛡️ Encryption & Security
- **Secure Encryption Mode** *(High Security)*: Generates randomized non-deterministic output per key to prevent statistical pattern analysis. Ideal for confidential messaging.
- **Fast Encryption Mode** *(High Performance)*: Generates deterministic output for maximum performance in trusted environments.
- **Private Key Protection**: Encrypt and decrypt data using a user-defined secret key. Decryption is impossible without the correct key.
- **Biometric & Password Security**: Lock private key access and app settings using Fingerprint / Face Unlock or custom password authentication.

---

### 🔧 Complete Text Conversion & Developer Suite

**Encryptor** features over 30+ conversion tools across 8 specialized categories:

#### 🧬 1. Encoding / Decoding
- **Base64**: Convert plain text and raw data to/from Base64.
- **Unicode**: Encode strings to Unicode escape sequences (`\uXXXX`) and decode back.
- **URL Encoding**: Percent-encode and decode text for web, API, and URI safety.

#### 🛡️ 2. Cryptographic Hashing
- **MD5**, **SHA-1**, **SHA-224**, **SHA-256**, **SHA-384**, **SHA-512** hashes for data integrity verification.

#### 🧾 3. Character Encodings & Byte Arrays
- **UTF-8**, **UTF-16**, **UTF-16LE**, **UTF-16BE**
- **US-ASCII**, **ISO-8859-1**, **CP1251** byte representation conversions.

#### 🔢 4. Number Systems Conversion
- **Decimal (Base-10)** ⇄ Binary, Octal, Hexadecimal
- **Binary (Base-2)** ⇄ Decimal, Octal, Hexadecimal
- **Octal (Base-8)** ⇄ Decimal, Binary, Hexadecimal
- **Hexadecimal (`0x0` & `0x00000000`)** ⇄ Decimal, Binary, Octal

#### 🧮 5. IEEE 754 Floating-Point Conversions
- **Decimal Float** ⇄ Float Binary, Float Octal, Float Hexadecimal, Float Hex (`0x0`), Float Hex (`0x00000000`).

#### 🎨 6. Color Code Conversions
- **Color Hex (`#AARRGGBB`)** ⇄ Decimal & RGB
- **Color Decimal** ⇄ Hex & RGB
- **Color ARGB** ⇄ Hex & Decimal

#### ⚡ 7. Binary Calculator & Bitstream
- **Binary Calculator**: Perform binary addition and subtraction directly.
- **Binary Bitstream**: Convert plain text into binary bitstreams and back.

---

### 🔍 Instant Search & Quick Actions
- **Live Search Bar**: Instantly filter all conversion tools and algorithms from the home screen.
- **Quick Action Toolbar**: One-tap Copy to Clipboard, Share to other apps, Swap/Exchange Input and Output, and Reset/Clear.
- **Full-Screen Text Editor**: Expand input or output text into a full-screen editor (`TextEditorActivity`) for convenient reading and editing of large payloads.
- **File Import & Export**: Import text directly from `.txt` files into input fields, and export conversion results as `.txt` files to storage.

---

### 🎨 Design & Personalization
- **Material 3 Dynamic Color**: Adapts to device wallpaper colors on Android 12+.
- **Primary Color Accent Picker**: Custom palette picker to personalize primary theme accents.
- **Theme Support**: Dark Mode 🌙, Light Mode ☀️, and System Default.
- **App Shortcuts**: Quick launcher shortcuts for instant navigation.

---

### 🪵 Diagnostics & Performance
- **Logging Mode**: Save logcat output to local storage via Storage Access Framework (SAF) for easy debugging.
- **Firebase Analytics & Crashlytics**: Integrated anonymous crash reporting and performance diagnostics to guarantee app stability.
- **OTA Updates**: Automatic update checking to keep the app up to date.
